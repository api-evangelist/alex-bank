# Alex Bank

> Alex Bank (Alex Bank Pty Ltd, ABN 13 627 244 848) is an Australian digital bank headquartered in Brisbane, and an active APRA-authorised deposit-taking institution (ADI). As a Consumer Data Right (CDR) data holder it publishes an unauthenticated Product Reference Data (PRD) API under the DSB Consumer Data Standards, and supports accredited-data-recipient sharing of savings, term deposit and personal loan data over the CDR FAPI security profile.

## APIs

- [Alex Bank CDR Product Reference Data API](https://www.alex.bank/legal/open-banking/): Public, unauthenticated Get Products / Get Product Detail endpoints. Base URL https://public.cdr.alex.com.au/cds-au/v1
